T3K WEBSITE – OWNER APPLICATION SYSTEM

Dateien:
- index.html       Hauptseite; oben rechts OWNER LOGIN
- members.html     Member-Seite
- bewerbung.html   Bewerbungsformular
- owner.html       Owner-Login und Bewerbungsübersicht
- api/applications.php  Server-API
- api/data/applications.json  gespeicherte Bewerbungen

WICHTIG:
Das Bewerbungs-Postfach benötigt einen Webserver mit PHP 8+ und aktivierten Schreibrechten für api/data/.
Die Website muss online unter einer PHP-fähigen Domain/Hosting laufen. Einfaches Öffnen von index.html auf dem iPhone/PC als lokale Datei speichert Bewerbungen nicht zentral.

Die Bewerbungen werden serverseitig gespeichert und sind danach im OWNER LOGIN aufrufbar.
